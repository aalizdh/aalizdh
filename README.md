# ⚡ Cyberpunk Interactive Portfolio

یک وب‌سایت پورتفولیو و رزومه تعاملی با تم سایبرپانک، بهینه‌سازی‌شده برای دسکتاپ و موبایل.

🔗 **دموی آنلاین:** [aalizdh.github.io/aalizdh](https://aalizdh.github.io/aalizdh/)

---

## 🛠 تکنولوژی‌ها و ابزارها

* **HTML5 & Tailwind CSS:** ساختار و طراحی المان‌های بصری نئونی
* **SVG & Dynamic Bezier Paths:** پیاده‌سازی ریل و مدارهای ارتباطی
* **Vanilla JavaScript:** انیمیشن پالس انرژی همگام با اسکرول (Scroll-driven Lerp Animation)
* **GitHub Pages:** میزبانی و استقرار مداوم (CI/CD)

---

## ✨ قابلیت‌های برجسته

* **پالس انرژی نوری تعاملی:** هدایت یک جریان نئونی در طول تایم‌لاین پروژه همگام با اسکرول کاربر
* **پایانه بازگشت فوتر (Terminal Return):** دکمه اسکرول نرم به بالا با افکت شارژ نوری
* **طراحی کاملاً واکنش‌گرا (Responsive):** سازگاری هندسی مدارها با ابعاد تبلت و موبایل
